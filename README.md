# PDFハンコリーダー v0.2.4

PDF.jsでPDFを表示し、その上に透明レイヤーを重ねてスタンプを配置するWebアプリのv0.2.4プロトタイプです。

v0.2.4では、拡大時の端切れ対策をさらに見直し、横位置スライダーが実際のPDF表示枠の横スクロールと連動するように修正しました。あわせて、対応ブラウザではローカルPDFも履歴からワンクリックで再オープンできるようにしました。

## 起動方法

### Windows

1. ZIPを展開します。
2. `start-windows.bat` をダブルクリックします。
3. ブラウザで `http://localhost:8000` が開きます。

### Mac

1. ZIPを展開します。
2. `start-mac.command` を実行します。
3. ブラウザで `http://localhost:8000` が開きます。

うまく実行できない場合は、ターミナルでこのフォルダへ移動して次を実行してください。

```bash
python3 -m http.server 8000
```

その後、Chromeなどで `http://localhost:8000` を開きます。

## 使い方

1. 「ローカルPDFを開く」からPDFを選ぶか、「PDF URLを入力」からオンラインPDFを開きます。
2. テキストPDFの場合、1ページ目の文字サイズを見て初期倍率を自動推定します。
3. 左側のスタンプを選びます。
4. PDF上をクリックするとスタンプが押されます。
5. ハンコ配置はブラウザの `localStorage` に自動保存されます。
6. 必要に応じて「書き出し」で配置JSONを保存できます。
7. 「JSONを読み込み」から配置JSONを読み込むこともできます。

## v0.2.4で修正・追加したこと

- 横位置スライダーの修正
  - PDF表示欄そのものの `scrollLeft` とスライダーを連動
  - PDFページが表示欄より大きいときだけ有効化
  - 表示直後のレイアウト確定後にスライダー範囲を再計算
- 拡大時の端切れ対策
  - PDF表示本体の幅をページ幅に固定
  - 小さいPDFは中央表示
  - 大きいPDFは左端から横スクロールできる構成に変更
- 履歴からワンクリックで開く
  - URL PDFは従来どおり履歴から再オープン
  - ローカルPDFは対応ブラウザでファイル参照をIndexedDBに保存
  - Chromeなど対応環境では履歴の「開く」から再オープン可能
  - 権限が切れた場合や非対応環境では、選び直しにフォールバック
- 起動補助ファイルを追加
  - `start-windows.bat`
  - `start-mac.command`

## 仕様

- Webアプリとして動作します。
- PDF.jsをCDNから読み込みます。
- PDFの現在ページをcanvasに描画します。
- canvasの上に透明なstamp-layerを重ねます。
- 初期スタンプは5種類です。
- 押したスタンプは移動・サイズ変更・個別削除できません。
- 位置はページ内の比率 `xRatio` / `yRatio` として保存します。
- ズームしても配置位置が追従するように、ページ内比率から再描画します。
- 履歴は `localStorage` の `pdf-hanko-reader:history:v0.2` に保存します。
- ローカルPDFのファイル参照は、対応ブラウザではIndexedDBに保存します。
- ハンコ配置はPDFごとのキーで `localStorage` に保存します。

## 注意

- CDNを使うため、インターネット接続が必要です。
- PDF自体にはスタンプを書き込みません。
- オンラインPDFは、配信元のCORS制限により開けないことがあります。
- `localStorage` 保存は同じブラウザ内の保存です。別PCや別ブラウザに移す場合はJSONを書き出してください。
- ローカルPDFはファイル名で紐づけます。同じ名前の別PDFを開いた場合は同じ保存データとして扱われます。
- ローカルPDFの履歴ワンクリック再オープンは、File System Access APIに対応したブラウザで動きます。Chrome系ブラウザでの利用を想定しています。
- スキャンPDFや画像だけのPDFでは文字サイズ検出はできません。その場合はページ幅ベースの初期倍率になります。
