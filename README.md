# PDFハンコリーダー v0.2.5

PDF.jsでPDFを表示し、その上に透明レイヤーを重ねてスタンプを配置するWebアプリのv0.2.5プロトタイプです。

v0.2.5では、A4縦以外やスキャンPDFでも表示が崩れにくいように、PDF表示エンジンを見直しました。PDF.jsから取得したページ本来の幅・高さを基準にし、「全体表示」「幅に合わせる」「手動」の表示モードを追加しています。

## 起動方法

### Windows

1. ZIPを展開します。
2. `start-windows.bat` をダブルクリックします。
3. ブラウザで `http://localhost:8000` を開きます。

### Mac

1. ZIPを展開します。
2. 必要に応じてターミナルで実行権限を付けます。

```bash
chmod +x start-mac.command
```

3. `start-mac.command` を実行します。
4. ブラウザで `http://localhost:8000` を開きます。

うまく実行できない場合は、ターミナルでこのフォルダへ移動して次を実行してください。

```bash
python3 -m http.server 8000
```

その後、Chromeなどで `http://localhost:8000` を開きます。

## 使い方

1. 「ローカルPDFを開く」からPDFを選ぶか、「PDF URLを入力」からオンラインPDFを開きます。
2. 初期表示は「全体表示」です。まずPDFページ全体の枠が表示されます。
3. 必要に応じて「幅に合わせる」または「手動」で倍率を変えます。
4. 左側のスタンプを選びます。
5. PDF上をクリックするとスタンプが押されます。
6. ハンコ配置はブラウザの `localStorage` に自動保存されます。
7. 必要に応じて「書き出し」で配置JSONを保存できます。
8. 「JSONを読み込み」から配置JSONを読み込むこともできます。

## 仕様

- Webアプリとして動作します。
- PDF.jsをCDNから読み込みます。
- PDFの現在ページをcanvasに描画します。
- canvasの上に透明なstamp-layerを重ねます。
- 初期スタンプは5種類です。
- 押したスタンプは移動・サイズ変更・個別削除できません。
- 位置はページ内の比率 `xRatio` / `yRatio` として保存します。
- ズームしても配置位置が追従するように、ページ内比率から再描画します。
- 履歴は `localStorage` の `pdf-hanko-reader:history:v0.2` に保存します。
- ローカルPDFのファイル参照は、対応ブラウザではIndexedDBに保存します。
- ハンコ配置はPDFごとのキーで `localStorage` に保存します。

## 注意

- CDNを使うため、インターネット接続が必要です。
- PDF自体にはスタンプを書き込みません。
- オンラインPDFは、配信元のCORS制限により開けないことがあります。
- `localStorage` 保存は同じブラウザ内の保存です。別PCや別ブラウザに移す場合はJSONを書き出してください。
- ローカルPDFはファイル名で紐づけます。同じ名前の別PDFを開いた場合は同じ保存データとして扱われます。
- ローカルPDFの履歴ワンクリック再オープンは、File System Access APIに対応したブラウザで動きます。Chrome系ブラウザでの利用を想定しています。
- PDFページの外で切れて作成されている内容は、リーダー側では復元できません。v0.2.5ではページ枠を表示し、「リーダーの表示切れ」か「PDF作成時点の切れ」かを判断しやすくしています。
